# Prem Sagar — HTML/CSS Portfolio

## Files
- `index.html` — portfolio structure and content
- `style.css` — responsive UI and animations/transitions
- `assets/profile.jpg` — put your profile photo here

## Replace your profile image
Open `index.html` and find:

```html
<img src="assets/profile.jpg" alt="Prem Sagar profile photo">
```

Replace `assets/profile.jpg` with your own image path, for example:

```html
<img src="images/my-photo.png" alt="Prem Sagar profile photo">
```

## Personal links
In `index.html`, replace the `href="#"` values for LinkedIn and GitHub with your real profile URLs.

The portfolio uses only HTML and CSS for its functionality/UI. Google Fonts are loaded externally; you can remove that import if you want a fully offline version.
